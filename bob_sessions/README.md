# Bob task sessions

The hackathon requires each team member's IBM Bob task session summaries for this project. Put them here:

- screenshots of Bob's task session summaries, one file per task, named `<date>_<task>_member<N>.png`
  (for example `2026-09-27_probe_member1.png`);
- exported session reports, if Bob offers an export.

**No personal information.** The hackathon guide asks for none. Before adding a file:
- crop or blur account emails, names and avatars that Bob's window shows;
- check that paths don't show a local user name.

Use `member1`, `member2`, and so on, never real names.

What each task was, and which code Bob wrote in it, is listed in `BOB_RUNBOOK.md` (step 5).
